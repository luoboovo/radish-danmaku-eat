# 小萝卜吃吃吃

<p align="center">
  <img src="cake.svg" width="112" alt="小萝卜吃吃吃图标">
</p>

一个使用 Python、PyQt5 与 [blivedm](https://github.com/xfgryujk/blivedm) 开发的 B 站直播互动投喂小游戏。观众可以通过弹幕和礼物增减食物，主播则能在透明游戏区域中拖动食物、移动食用者以及使用圆形范围拾取。

> 本项目是非官方开源项目，与哔哩哔哩没有隶属或合作关系。

## 下载 Windows 版

不想配置 Python 环境时，可以前往 [GitHub Releases](https://github.com/luoboovo/radish-danmaku-eat/releases/latest) 下载：

- `*-安装版.exe`：带中文安装向导、开始菜单快捷方式、礼物图标和卸载程序的安装版（推荐）。
- 不带“安装版”字样的 `.exe`：无需安装的单文件便携版。
- `*.sha256.txt`：对应安装包的 SHA-256 校验文件。

## 功能特色

- 白色极简直播控制台与纯透明置顶游戏窗口相互独立。
- 手动圈选游戏区域，可在浏览器、游戏或其他窗口前运行。
- 支持 PNG、JPG、WebP、BMP、SVG 和 GIF 食物/食用者贴图。
- 内置“老鼠吃大米”“落叶进桶”“猫咪吃小鱼”“星星收藏瓶”四套透明 PNG 主题模板，一键替换食物与食用者。
- 支持从空白模板开始制作，并把当前食物/食用者组合保存为可复用的自定义模板。
- 没有设置食物贴图时，默认使用内置胡萝卜。
- 食物支持自然下落、随机旋转、稳定堆积以及中间取走后向下补位。
- 食物从区域底部横向铺开并逐层向上自然堆积，数量足够时可堆满整个区域。
- 单个拖拽与圆形范围拾取；单次范围抓取上限默认 100，可在控制台修改。
- 食用者可以自由移动，食物、食用者和范围尺寸会自动适配显示器缩放。
- 可配置弹幕关键词，以及礼物增加、减少、乘以、除以、清空和“刮大风”规则。
- 礼物模板是真正的整套玩法方案：一套模板可同时包含多个礼物的加减、乘除、清空、刮风和范围拾取反馈；支持应用、新建空白、另存多个模板和删除自定义模板。
- 内置“日常投喂”“倍率挑战”“大风派对”三套示例，切换模板会整套替换当前礼物规则，之后仍可逐条修改。
- “刮大风”会播放透明风线并把当前全部食物卷到空中，逐次随机增加或减少当前数量的 10%～50%，最后让食物重新自然下落堆积。
- 填写房间号后自动同步该直播间的礼物目录与图标并缓存到本地，礼物规则可搜索选择，也可手动刷新。
- 礼物浮窗优先使用透明 PNG 图标；投喂/增加为红色、减少为绿色、范围拾取为黄色。
- 透明游戏区域按规则数量逐条常驻显示“礼物图标 + 礼物名 + 作用”，支持丝滑拖动、记忆位置和控制台开关；新增食物或刷新画面后仍保持可见，收到礼物时会更新本次实际作用。
- 礼物可以限时开启圆形范围拾取，断线后自动重连。
- 独立透明文字展示框显示“已吃 / 剩余”，支持拖动和滚轮缩放。
- “星星收藏瓶”主题每次投入星星都会随机显示一条手绘粉色祝福气泡；祝福语可在显示设置中逐行编辑。
- 直播互动日志只记录观众弹幕和礼物，不记录主播手动操作。
- 内置增加、减少、吃掉和礼物四种音效，也可分别上传、恢复默认和试听。
- 每张食物贴图可单独绑定吃掉音效，也可以一键给全部食物设置同一个音效。
- 游戏运行期间可更换贴图、音效、排列模式及直播规则，点击“保存并应用”即可生效。
- 默认手动加减步长为 100，默认圆形拾取半径为 50；游戏音效和礼物浮窗开关集中在“游戏控制”首页。

## 运行环境

- Windows 10/11
- Python 3.10 或 3.11
- PyQt5 5.15

## 安装与启动

```powershell
git clone https://github.com/luoboovo/radish-danmaku-eat.git
cd radish-danmaku-eat

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python main.py
```

项目在 `vendor/` 中包含从 blivedm 官方源码构建的 1.1.7 wheel，因此安装依赖时不需要本机 Git，也不会安装到同名的非官方 PyPI 包。

## 快速使用

1. 启动程序，先把直播间房间号留空进行离线测试。
2. 在“显示设置”中双击内置主题模板，或自行添加食物和食用者贴图；当前组合也可以保存为自定义模板。
3. 点击右上角“保存并圈选区域”，按住鼠标左键拖出游戏范围。
4. 在控制台使用 `+N`、`-N` 和“范围拾取”测试游戏。
5. 填写直播间房间号，程序会自动同步礼物与图标；在“直播互动”中直接搜索选择礼物并配置规则。鼠标滚轮不会再误改下拉选项。
6. 游戏运行中修改设置后，点击“保存并应用”即可即时更新。

普通模式下按住一个食物拖动，松手后食物会从当前位置自然下落。直接拖到食用者范围内，或从食用者上方让食物落下，都会完成投喂。

范围模式下可以按住食物抓取设定半径内的多个食物，也可以从透明空白处拖动，画出一个可视化圆形范围。命中数量超过设置上限时，会优先抓取离圆心最近的食物。

## 直播间连接

只填写直播间网址末尾的数字房间号，例如：

```text
https://live.bilibili.com/123456
                              └─ 房间号：123456
```

连接成功后，控制台顶部会显示连接状态。弹幕规则支持整句匹配和包含匹配。礼物目录会在填写房间号后自动同步，也可以点击“同步B站礼物”刷新；同步失败时仍可继续使用上一次的本地缓存或手工输入礼物名称。

礼物图片缓存在程序当前目录下的 `gift_images` 文件夹。目标图片已经存在时会直接复用，不会重复下载；需要重新下载时可删除对应图片后再次同步。

### SESSDATA 是否必需

SESSDATA 不是必需项。留空仍然可以监听弹幕和礼物，但用户名可能脱敏，UID 也可能显示为 0。

如果需要未脱敏身份：

1. 在浏览器登录 B 站。
2. 按 `F12` 打开开发者工具。
3. 进入“应用（Application）→ Cookies → `https://www.bilibili.com`”。
4. 找到 `SESSDATA` 并复制它的值到控制台。

> SESSDATA 等同于登录凭据。不要截图、分享或提交包含它的 `config.json`。本仓库已通过 `.gitignore` 排除真实配置文件。

## 机器码授权

官方构建支持离线机器码授权。首次启动会显示本机机器码，用户把机器码发给授权方，收到以 `RDEC1.` 开头的密钥后即可激活。授权支持一天、七天、一个月、一个季度和永久五种时长；限时授权从密钥生成时开始计算，运行期间每分钟复核一次，到期后会退出且无法继续进入控制台。

控制台左下角会实时显示剩余天数和时分秒，并标明准确到期时间；永久授权显示“永久授权”。点击旁边的小号“重新激活”按钮可以随时粘贴新密钥续期，无需关闭游戏或重新启动控制台。

授权使用 Ed25519 非对称签名：客户端和公开源码只包含验签公钥，签发私钥及私用密钥生成器不能上传到仓库、Release 或发送给普通用户。`license.json` 已被忽略，不会提交用户密钥。

> 本项目仍是开源软件。机器码授权可以限制官方 EXE 的直接复制使用，但无法阻止有开发能力的人修改开源代码并移除授权检查；若要更强的商业保护，需要闭源关键模块或增加联网授权服务。

主要配置包括：

- 食物与食用者贴图路径
- 自定义主题模板名称及其食物/食用者组合
- 初始数量、手动加减步长与显示尺寸
- 全宽重力分层堆积
- 弹幕关键词和加减数量

- 礼物作用浮窗开关
- 自定义音效路径

## OBS 采集

推荐使用 OBS 的“显示器采集”，透明游戏层可以覆盖在任意桌面窗口上，透明区域仍能点击后方程序。

如果必须使用“窗口采集”，请选择 `小萝卜吃吃吃 [透明游戏区域]`，使用 Windows Graphics Capture 并启用透明度。部分 OBS 或显卡组合会把透明窗口显示为黑色，此时请改用“显示器采集”。不要最小化透明游戏窗口；被 Windows 最小化的窗口无法继续被采集。

## 从源码打包 EXE

```powershell
pip install pyinstaller

pyinstaller --noconfirm --onefile --windowed `
  --name "小萝卜吃吃吃-v2.0.0" `
  --icon "cake.ico" `
  --add-data "cake.svg;." `
  --add-data "assets;assets" `
  --collect-all blivedm `
  main.py
```

生成结果位于 `dist/`。该目录默认不会提交到 Git 仓库，建议通过 GitHub Releases 分发打包版本。

## 构建 Windows 安装版

先按上一节生成便携版，并将文件命名为 `radish-danmaku-eat-v版本号-windows.exe`。安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 后执行：

```powershell
& "$env:LOCALAPPDATA\Programs\Inno Setup 6\ISCC.exe" `
  /DAppVersion=2.0.0 installer.iss
```

安装包输出到 `dist/小萝卜吃吃吃-v2.0.0-安装版.exe`。安装版采用当前用户安装方式，不要求管理员权限；个人配置会保存在安装目录中，卸载时默认保留。安装包同时附带当前 `gift_images` 礼物图标目录，首次离线启动也能显示已经缓存的礼物图片。
